## Preview

| Key | Action |
|---|---|
| `j` `k` `↑` `↓` | Scroll a line |
| `Space` `b` `PgDn` `PgUp` | Scroll a page |
| `d` `u` | Scroll half a page |
| `g` `G` `Home` `End` | Top, bottom |
| `Tab` `Shift+Tab` | Next, previous link |
| `Enter` or click | Follow the link |
| Drag | Select text and copy it (`Ctrl+C` copies it again) |
| `/` | Find (`n` `N` next, previous) |
| `o` | Open a file or URL in a new tab (`Tab` completes paths) |
| `` Ctrl+` `` | Next tab (`Shift` for previous) |
| `[` `]` | Previous, next tab |
| `Ctrl+W` | Close tab, or click the `×` on a tab under the mouse |
| `t` | Next color palette |
| `r` | Reload the file |
| `F12` | Performance HUD |
| `F11` | Save the last frames to a file, for a bug report |
| `Ctrl+Q` | Quit |
