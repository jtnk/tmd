## Editor (experimental)

`e` edits in place, and `Esc` comes back.

| Key | Action |
|---|---|
| `Esc` or `Ctrl+R` | Back to preview |
| `Ctrl+S` | Save |
| `Ctrl+Z` `Ctrl+Y` | Undo, redo |
| `Ctrl+B` `Ctrl+I` `Alt+C` | Wrap the selection in `**`, `*` or a code span (`Alt+I` also italicizes) |
| `Ctrl+K` | Link the selection |
| `Ctrl+T` | Tidy whitespace |
| `Ctrl+F` `Ctrl+G` | Find, next |
| `Ctrl+A` | Select all |
| `Ctrl+C` `Ctrl+X` `Ctrl+V` | Copy, cut, paste |
| `Shift` + arrows | Select |
| `Ctrl` + arrows | Move by word |
| `` Ctrl+` `` | Next tab (`Shift` for previous) |
| `Ctrl+O` | Open a file or URL in a new tab |
| `Ctrl+W` | Close tab, or click the `×` on a tab under the mouse |
| `Ctrl+Q` | Quit |

Hold `Shift` to select text with the mouse the terminal's own way.
